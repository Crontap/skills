# Crontap Agent Skills

Agent Skills for managing scheduled HTTP jobs, uptime monitors, and heartbeats with Crontap.

After the skill set is synced, install it with:

```bash
npx skills add Crontap/skills
```

The canonical source is maintained in the [Crontap monorepo](https://github.com/danmindru/apihustle/tree/main/skills).
